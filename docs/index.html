Astro Drift

An Asteroids-style arcade game implemented across eight game engines, side by side, as a comparison study.

Every port runs the same drifting-ship physics with identical inertia constants (THRUST=350, ROT=4, DRAG=0.55), then layers its own engine-specific twist on top. Three of them are playable in your browser below; the rest are source-of-truth projects you open in their respective editors.

Controls (every version)

← →   rotate
↑     thrust
↓     brake
Del   fire
Ins   toggle engine special (CRT shader / AI autopilot)
End   restart after game over
Esc   quit

Playable in browser

Godot 4 → LIVE
GDScript
Full game with waves, lives, scoring, splitting asteroids. Twist: CRT post-process shader — phosphor bloom, scanlines, barrel distortion, chromatic aberration. Press Ins to toggle.
Love 2D → LIVE
Lua
Twist: authentic 1979 vector-display phosphor. Every shape drawn three times — wide additive halo + narrow halo + crisp stroke with per-frame brightness flicker. Looks like a real CRT.
PyGame → LIVE
Python
Twist: numpy procedural nebula + AI autopilot (press Ins). The backdrop is generated entirely from numpy Gaussians + noise; the AI is a 20-line heuristic that locks the nearest asteroid and dodges anything inside an 80px danger radius.

Open in editor (source on GitHub)

Defold ↗ SOURCE
Lua
King's open-source mobile engine. Flat game-object + collection architecture. Hand-authored game.project, collections, GOs, scripts, input bindings, GUI scene.
Solar 2D ↗ SOURCE
Lua
Community continuation of Corona SDK. Mobile-first Lua framework with letterbox content scaling. Opens in the Solar 2D Simulator.
Panda 3D ↗ SOURCE
Python
Disney VR's open-source 3D engine. Same game projected into 3D space — box-mesh ship on a lit XY plane with world-bound wrap. pip install panda3d && python main.py.
Unity ↗ SOURCE
C# (MonoBehaviour)
Targets Unity 2022.3 LTS. PlayerController, AsteroidController, BulletController, GameManager plus Unity-flavored juice: ThrustTrail (particle emission), CameraShake (trauma-based), ExplosionEffect, SfxManager.
Stride ↗ SOURCE
C# (.NET 8)
Stride 4.2 (formerly Xenko). SyncScript-based player and bullet on the XZ plane. ControlsUi.cs builds the overlay with Stride.UI.Canvas + TextBlock.
