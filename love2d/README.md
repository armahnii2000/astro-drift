# Astro Drift — Love 2D

A standalone version of the Astro Drift drifting-ship demo, built with [LÖVE 2D](https://love2d.org/) 11.x. Pure Lua.

## Run

```sh
love .
```

Or drag the `love2d` folder onto the LÖVE executable.

## Files

- `main.lua` — game loop, input, ship physics, bullets, screen wrap, starfield
- `conf.lua` — window config (960×540, vsync on)

## Controls

`W`/`↑` thrust · `A`/`D`/`←`/`→` rotate · `Space`/`J` fire · `Esc` quit
