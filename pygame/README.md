# Astro Drift — PyGame

The Astro Drift drifting-ship demo in [PyGame](https://www.pygame.org/) 2.x. Pure Python, no extra assets.

## Run

```sh
python -m pip install -r requirements.txt
python main.py
```

## Files

- `main.py` — single-file implementation: game loop, input, ship physics, bullets, screen wrap, starfield
- `requirements.txt` — `pygame>=2.5`

## Controls

`W`/`↑` thrust · `A`/`D`/`←`/`→` rotate · `Space`/`J` fire · `Esc` quit
